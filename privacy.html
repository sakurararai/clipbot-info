プライバシーポリシー

clipbot ・ 制定日 2026-10-15

アクセスする情報

clipbot がアクセスするのは、運営者本人の Google ドライブだけです。ほかの方の Google アカウントやデータにはアクセスしません。

使い道

切り出した動画ファイルを Google ドライブの指定フォルダにアップロードし、そのフォルダのリンクを取得するためだけに使います。

しないこと

  • 指定フォルダ以外のファイルを読み取ること
  • データを第三者に渡したり、販売したりすること
  • データを広告に使うこと

Google API サービスのデータの扱い

Google API から受け取った情報の使用と転送は、Limited Use の要件を含む Google API Services User Data Policy に従います。
